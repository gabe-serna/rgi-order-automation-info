# Privacy Policy

## Overview

RGI Order Automation is an internal business tool intended for authorized Rare Genetics personnel.

## Data Access and Usage

The extension accesses Google Sheets, Google Drive, and the Rare Genetics order management system to perform authorized order-processing operations.

Google user data is accessed exclusively to provide the application's intended functionality.

## Data Storage and Processing

Application logic is executed locally within the user's browser. The extension does not transmit user data to developer-controlled servers.

Authentication information and application settings may be stored locally within the browser as necessary for application functionality.

## Data Sharing

The extension communicates directly with Google and Rare Genetics services to perform authorized operations. User data is not sold, used for advertising, or shared with unrelated third parties.

The extension does not use analytics, telemetry, or tracking services.

## Google API Compliance

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
